# 🚌 חבילת הקוד המלאה לתחבורה ציבורית בירושלים (TachboraBot & OpenBus Line 61)

חבילת תוכנה מלאה ומתקדמת לניטור קווי אוטובוס בירושלים, שליפת נתוני אמת והיסטוריה מ-OpenBus (הסדנא לידע ציבורי), והגשת תלונות רשמיות מובנות למשרד התחבורה ולעיריית ירושלים.

---

## 🌟 עיקרי היכולות בחבילה

1. **שליפת נתוני עומק לקו 61 (הר הצופים -> רמות | תחנה 1412 - מרכז מסחרי/ההגנה):**
   * שליפת זמני יציאה מתוכננים ממוצא (הר הצופים) והגעה מתוכננת לתחנה 1412 מתוך GTFS.
   * שליפת זמני אמת (SIRI) בדיעבד (פוסט-הוק) לכל נסיעה: שעת הגעה בפועל, חישוב איחורים, מספר לוחית רישוי של האוטובוס, ומהירות/שהייה בתחנה.
   * ייצוא ישיר לדוחות CSV, JSON, וסנכרון מול Google Sheets.
2. **בוט טלגרם אינטראקטיבי (`bot.py`):**
   * **התאמה מלאה לטופס משרד התחבורה (`PublicTransportRequest@mot.gov.il`):** פיצול שם פרטי ושם משפחה, תעודת זהות (9 ספרות), טלפון נייד, דוא"ל, עיר/יישוב, ורחוב ומספר בית למשלוח דואר.
   * **זיכרון פרופיל משתמש:** שמירת פרטי הזיהוי ב-SQLite והצגתם לאישור בלחיצת כפתור אחת בכל פנייה חוזרת.
   * **חיפוש תחנות חכם ב-OpenBus:** אפשרות להקליד מספר תחנה או שם תחנה/רחוב (כגון "ההגנה", "בר כוכבא", "מרכז מסחרי") ובחירה מרשימת כפתורים תואמת.
   * **זיהוי לוחיות רישוי אוטומטי:** סריקת SIRI בטווח של 15 דקות לפני ואחרי האירוע להצגת האוטובוסים הרלוונטיים.
   * **פקודת `/line61`:** בדיקה מהירה של האוטובוסים הפעילים בזמן אמת בקו 61 בתחנה 1412.
3. **שילוב מלא עם Google Sheets ו-Gmail:**
   * סקריפט Google Apps Script (`google_apps_script.js`) הקולט תלונות לגיליון, ושולח דוא"ל רשמי מובנה ישירות מכתובת ה-Gmail של המשתמש ל-`pniotcrm@mot.gov.il` ולעיריית ירושלים.
   * מודול Apps Script עצמאי לסנכרון נתוני האמת של 851 הנסיעות בגיליון.

## 📁 מבנה הקבצים בחבילה

| קובץ | תפקיד |
| :--- | :--- |
| `extract_line_61.py` | מודול CLI עצמאי לשליפת נתוני קו 61 (תכנון מול אמת, איחורים ולוחיות) מ-OpenBus |
| `bot.py` | מנוע בוט הטלגרם המרכזי עם כל שלבי השיחה המותאמים למשרד התחבורה |
| `transit_api.py` | ממשק לקריאות API מול OpenBus Stride API (חיפוש תחנות, מפעיל, SIRI ולוחיות) |
| `database.py` | שכבת מסד נתונים SQLite עם שמירת משתמשים, היסטוריית תלונות ומנגנון הגנה מנעילות |
| `google_apps_script.js` | קוד Apps Script להדבקה ב-Google Sheet (קליטת Webhook, משלוח מיילים וסנכרון קו 61) |
| `sheets_sync.py` | סנכרון תלונות מול שירותי ענן ו-Google Sheets |
| `notifier.py` | מודול הפקת מספרי פנייה (`MOT-...`) וניסוח הודעות דוא"ל רשמיות |
| `date_parser.py` | מפענח תאריכים ושעות בעברית חופשית ("אתמול ב-14:30", "היום בבוקר") |
| `config.py` | טעינת משתני סביבה והגדרות מערכת |
| `requirements.txt` | חבילות פייתון נדרשות (`python-telegram-bot`, `httpx`, `playwright`) |

## 🚀 הוראות הפעלה ושימוש

### 1. שליפת נתוני קו 61 בירושלים (הר הצופים -> רמות | תחנה 1412)
להפעלת שליפת נתונים היסטוריים מ-OpenBus:
```bash
# שליפת נתוני השבוע האחרון (ברירת מחדל: 7 ימים)
python3 extract_line_61.py

# שליפת נתונים של 30 הימים האחרונים וייצוא לקובץ מותאם אישית
python3 extract_line_61.py --days 30 --csv line_61_monthly.csv --json line_61_monthly.json
```

### 2. הפעלת בוט הטלגרם
```bash
# 1. התקנת חבילות
pip install -r requirements.txt

# 2. הגדרת קובץ .env עם הטוקן של הבוט
cp .env.example .env
# ערוך את .env והכנס את TELEGRAM_BOT_TOKEN ו-SHEETS_WEBHOOK_URL

# 3. הפעלת הבוט
python3 bot.py
```

### 3. התקנת Google Apps Script בגיליון המעקב
1. פתח את הגיליון שלך ב-Google Sheets.
2. לחץ בתפריט העליון על **הרחבות (Extensions)** -> **Apps Script**.
3. הדבק את תוכנו של הקובץ `google_apps_script.js`.
4. לפריסת ה-Webhook: לחץ על **Deploy** -> **New deployment** -> בחר **Web app** -> הגדר גישה ל-**Anyone** -> העתק את ה-Web app URL לתוך ה-`SHEETS_WEBHOOK_URL` בקובץ `.env`.
5. לעדכון זמני האמת של נסיעות קו 61 בגיליון: בחר בפונקציה `syncLine61Arrivals` ולחץ **Run**.
