# 🚌 Tachborabot - בוט תלונות תחבורה ציבורית (ירושלים ומשרד התחבורה)

בוט טלגרם חכם המיועד לנוסעי התחבורה הציבורית בירושלים.

## 🌟 יכולות חדשות שנוספו
1. **זיהוי תחנה אוטומטי:** קליטת מספר תחנה (קוד תחנה) ושליפת שם התחנה ממאגר GTFS.
2. **כיוון נסיעה:** ציון מדויק של כיוון הנסיעה עבור משרד התחבורה.
3. **שליפת לוחיות רישוי בטווח +-15 דקות:** איתור כל האוטובוסים שחלפו בתחנה 15 דקות לפני ואחרי שעת האירוע באמצעות SIRI.
4. **איתור ופרטי נהג:** שיוך שם נהג / תג נהג או הכוונה לאיתור דרך סידור העבודה.
5. **יצירת פנייה רשמית במשרד התחבורה:** חיבור לטופס [PublicTransportRequest@mot.gov.il](https://govforms.gov.il/mw/forms/PublicTransportRequest@mot.gov.il?gbxid=0), הפקת מספר פנייה מעקב, ומשלוח אוטומטי בדוא"ל למתלונן ולעיריית ירושלים.

## 🚀 הרצה מקומית / Codespaces
```bash
pip install -r requirements.txt
python bot.py
```
