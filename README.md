# בוט דיווח תלונות תחבורה ציבורית - ירושלים ומשרד התחבורה

בוט טלגרם חכם המאפשר לנוסעים בירושלים להגיש תלונה רשמית על קווי אוטובוסים.

## יכולות מרכזיות
1. **זיהוי מפעיל אוטומטי:** זיהוי חברת האוטובוסים לפי מספר הקו ממאגרי GTFS של משרד התחבורה.
2. **איתור לוחית רישוי בזמן אמת:** שליפת מספרי רישוי של אוטובוסים שנסעו בקו לפי נתוני SIRI.
3. **דיווח כפול ומקבילי:** שליחת התלונה הרשמית בדוא"ל במקביל למשרד התחבורה (`pniotcrm@mot.gov.il`) ולמחזיק תיק התחבורה בעיריית ירושלים (`david_zo@jerusalem.muni.il`), עם עותק למתלונן.

## התקנה והרצה
```bash
pip install -r requirements.txt
playwright install chromium
cp .env.example .env
# יש לערוך את .env ולהזין את TELEGRAM_BOT_TOKEN ופרטי ה-SMTP
python bot.py
```
